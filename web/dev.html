Back to the app

Needs Chrome or Edge on desktop. Close the official keyboard app first.

2. Read test (read only, never saves to the keyboard)

Follows the vendor app's read sequence. The "zero staging buffer" step in it writes zeros to the keyboard's temporary buffer only.


3. Dump memory (read only)

Reads the keyboard 8 bytes at a time and looks for the default key layout (1,2,3,4,5,Enter,9,8,7,6,0,`).


4. Key layout (read only)

Reads the two key tables found in the dump (at 0x0020 and 0x0128) and shows key names. Also lets you save a backup file of the whole dump.

5. Edit one key (WRITES to the keyboard) — table @0x0128

Saves the original value first, writes one byte, reads it back to verify. Test with a key you can undo. Then press Restore.

7. Find the true key map (calibrate)

A. (keyboard connected) Write a test pattern: each key gets its own letter. A backup is downloaded first.
B. Close tab, replug, reopen this page (no need to connect), then Start calibration and press each key when asked. The editor then uses the real map.

6. Key editor (WRITES to the keyboard) — table @0x0128

1) Load, 2) change the drop-downs, 3) Apply. A backup file is downloaded before the first write. Afterwards close this tab and replug the keyboard.

Lab: find what freezes the keys (press keys in Notepad after EACH button)

Open Notepad. After each button, type on the keyboard and note if it still types. Press the buttons in order and stop when the keys freeze.
